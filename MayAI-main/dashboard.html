Responses

서버 응답은 기본 허용입니다.
응답 정책에 매칭되면 MONITOR 모드에서는 기록만 하고, ENFORCE 모드에서는 차단합니다.

Response Policies

인증된 요청자, 실제 목적지, 응답 탐지 항목으로 매칭합니다.
조건이 구체적인 정책이 우선 순위보다 먼저 적용되고, 완전히 동률일 때만 DENY가 이깁니다.
정책이 없으면 응답은 허용됩니다.

MONITOR = DENY 매칭도 기록만 · ENFORCE = 실제 차단

Agents

게이트웨이를 사용할 수 있는 AI 에이전트 목록입니다.
등록되지 않은 ID는 게이트를 통과할 수 없습니다.

Request Policies

모든 요청에 적용됩니다.
명시적 DENY가 항상 ALLOW보다 우선하고, 그다음은 가장 구체적인 정책, 마지막으로 priority 숫자가 작은 정책 순입니다.

Events
