응답

서버 응답은 기본 허용입니다.
응답 정책에 매칭되면 모니터링 모드에서는 기록만 하고, 차단 모드에서는 응답을 막습니다.

응답 정책

인증된 요청자, 실제 목적지, 응답 탐지 항목으로 매칭합니다.
조건이 더 구체적인 정책이 먼저 적용되고, 완전히 동률일 때만 차단(DENY)이 이깁니다.
정책이 없으면 응답은 허용됩니다.

모니터링 = 차단 정책에 매칭돼도 기록만 · 차단 = 실제로 응답 차단

에이전트

게이트웨이를 사용할 수 있는 AI 에이전트 목록입니다.
등록되지 않은 ID는 게이트를 통과할 수 없습니다.

요청 정책

모든 요청에 적용됩니다.
명시적 차단(DENY)이 항상 허용(ALLOW)보다 먼저 적용되고, 그다음은 가장 구체적인 정책입니다.

MAC 보안 등급

내부 STDIO 통신에만 적용되는 강제 접근통제(MAC)입니다. 요청 정책을 통과해도 아래 두 규칙을 어기면 차단됩니다.
① 상위 등급 접근 금지: 에이전트 허가 등급보다 높은 도구·리소스·프롬프트는 쓸 수 없습니다.
② 하위 등급 유출 금지: 높은 등급 데이터를 받은 세션은 그보다 낮은 등급 대상으로 쓰기·외부 전송을 할 수 없습니다.
라벨이 없는 대상은 L4 핵심기밀로 간주합니다. 세션 등급은 올라가기만 하고, 에이전트가 다시 인증하거나 관리자가 초기화할 때만 L1로 돌아갑니다.

세션 등급

에이전트 실행 단위(세션)마다 지금까지 받은 데이터 중 가장 높은 등급입니다. 같은 실행에서 띄운 STDIO 서버들은 한 세션을 공유합니다.

에이전트 신뢰

STDIO 제로 트러스트의 에이전트별 신뢰 상태입니다. 세션은 초기화할 수 있어도 이 상태는 재시작·재인증으로 바뀌지 않습니다.
정상 → 의심(읽기만, 허용 등급 이하) → 침해(모든 요청 차단, 세션·토큰 폐기) 순으로 자동 전환되고, 침해에서 돌아오려면 복구 요청 → 토큰 교체 → 관리자 승인 → 관찰 → 관찰 종료를 거쳐야 합니다.

자동 전환 기준

임시 운영값입니다(검증된 표준 수치 아님). 횟수는 마지막 검증(복구 승인·검증 완료) 이후부터 셉니다. 위반 = 에이전트 스스로의 고위험 요청(상위 등급 접근, 유출 시도, 민감 경로, 위험 명령). 노출 = 에이전트가 받은 인젝션(의심까지만 반영).
